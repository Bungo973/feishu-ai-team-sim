# AI 模拟公司 · 项目助理演练

用 AI 模拟一个小公司的市场部项目组：8 个 AI 角色（项目组同事，加上产品、供应商、人事等对接人）、3 个并行项目、15 个工作日。你是新来的**项目助理**，在**飞书**里用群聊、私聊、多维表格、自动化管理这个团队。

- 同事会拖延、报喜不报忧、临时改需求、忘记口头布置的任务。这些由**规则**决定，不是 AI 随口编的。
- 进度、工时、审批、事件结果由代码确定性计算；AI 只负责"说话"（演员）和"评判你的动作"（导演）。
- 你的每个动作（追问、要链接、上报、找领导调整排期、搭流程和工具）都会被导演评估，改变后面的走向。每个中午和下班，导演会私聊你一条「导演复盘」。

> ⚠️ **防剧透**：玩家只需要读 `README.md`、`docs/玩家手册.md`、`docs/飞书配置指南.md`。
> **不要打开** `director/`、`state/`、`src/ai_company_sim/events.py`、`tests/`，以及根目录的 `AI模拟公司设定包.md`——里面是剧情、隐藏规则和真实进度。

## 你需要准备

| 东西 | 说明 |
|---|---|
| 一个飞书账号 | 自己新建一个团队（别用真实工作空间），你是里面唯一的真人，同事全是机器人 |
| 一个大模型 API Key | 任何 OpenAI 兼容接口：DeepSeek（默认）、通义千问、Kimi、智谱……；也支持 Claude |
| [uv](https://docs.astral.sh/uv/) | 管理 Python 环境，`uv` 会自动装好需要的 Python |

费用：整局 15 天调用大模型约几块到二三十块钱（DeepSeek 价格，以平台为准）。

## 第 1 步：装好、离线试跑（10 分钟）

```bash
cd ai-company-sim
uv sync --extra feishu
cp .env.example .env        # 用文本编辑器打开 .env，填 LLM_API_KEY
```

用别的平台：改 `.env` 里的 `LLM_BASE_URL` 和两个模型名 `MODEL_DIRECTOR` / `MODEL_ACTOR`。

先**离线试跑**一天（不调用大模型、不花钱，消息是占位文字，只确认程序能跑）：

```bash
LLM_MODE=offline uv run sim init --force
LLM_MODE=offline uv run sim start
LLM_MODE=offline uv run sim noon -y
LLM_MODE=offline uv run sim end -y
```

看到 "D1 结束" 就说明一切正常。

## 第 2 步：配飞书（约 1 小时）

照 [`docs/飞书配置指南.md`](docs/飞书配置指南.md) 做：建团队和两个群、为导演和每个同事建一个飞书应用（机器人）、导入任务表、检查连接。

## 第 3 步：开始玩

```bash
uv run sim init --force     # 正式初始化（会清掉试跑数据；换个剧情加 --seed 123）
uv run sim serve            # 保持开着，整局都在飞书里进行
```

在飞书里私聊**导演**：

| 发给导演 | 作用 |
|---|---|
| `上班` | 开始新的一天，上午的消息按模拟时间陆续出现 |
| `中午` | 结算上午、开始下午；导演私聊你上午的复盘 |
| `下班` | 结束今天：日报、晚上的消息、当天复盘 |
| `暂停` / `继续`、`快进`、`速度 20`、`状态` | 控制模拟时间 |
| `记录：……` | 补记自动记录不到的事：写了文档（附飞书链接）、上线了一个流程或工具、打了个电话 |

- **私聊同事**：直接点开他们的机器人聊天；**在群里 @某人**，他会在群里回你。
- **自动记录**：你的群发言、私聊、对任务表的修改（每次发"中午""下班"时比对）。
- **上线了流程或工具**（表单、自动化、机器人……）：在群里公告，并给导演发一句"记录：上线了……"，导演才知道它存在。
- 一个模拟日在现实里大约 30–60 分钟。建议每天玩 2–3 个模拟日，全程一周左右。

世界观、同事、项目、模板、可以做的流程改进：看 [`docs/玩家手册.md`](docs/玩家手册.md)。

## 第 4 步：结束之后

```bash
uv run sim report    # 结局报告 output/结局报告.md + 指标 output/metrics.csv
uv run sim stats     # 你每天的工作量：私聊追问、群发言、改表次数（output/workload.csv）
```

`metrics.csv`（逾期数、日报提交率、审批等待、信任值）可以导入飞书多维表格做前后对比仪表盘。

## 可选：AI 进度助手（示例工具）

[`../ai-assistant/`](../ai-assistant/README.md) 是作者第一局里搭的提效工具：一个能对话的飞书机器人，比对群聊、日报和任务表，列出要核实 / 要催 / 快到期的事，并能按你的话改任务表。

它和模拟器**完全隔离**：只读飞书和 `../shared/clock.jsonl`（模拟时钟），不读模拟器的任何代码和存档。配置了它的 `.env`，`sim serve` 会顺带启动它。想自己从零搭工具的话，就别配它。

## 其他命令

| 命令 | 作用 |
|---|---|
| `uv run sim status` | 现在是第几天、今天日程 |
| `uv run sim undo D5` | 回到 D5 下班时（AI 出错、想重来某一天） |
| `uv run sim weekly` | AI 周报初稿（读本周日报） |
| `uv run sim feishu-check` | 检查飞书机器人和任务表 |

## 常见问题

- **AI 报错 / 超时**：重发刚才的命令。`start` 失败先 `uv run sim undo D{前一天}`；`noon` 失败先 `uv run sim undo D{今天}-morning`。
- **提示"输出格式不对，重试"**：模型偶尔没按格式输出，会自动重试。经常失败就把 `MODEL_DIRECTOR` 换成更强的模型。
- **机器人不回话**：看 `sim serve` 的终端有没有报错，再跑 `uv run sim feishu-check`。最常见的原因是改了权限没重新发布应用，或者机器人不在群里。
- **想在终端里玩（不用飞书）**：见 [`docs/终端玩法.md`](docs/终端玩法.md)。
- **对外展示**：一律说明是"自建的模拟演练项目"，不要包装成真实经历（手册 11.5 有现成的声明）。
- **和原设定包有哪些不同**：`director/调整记录.md`（含剧透，玩完再看）。
