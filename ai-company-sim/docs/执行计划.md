# 执行计划：从模拟演练到求职视频

> 这份计划只写你要做的事和怎么做，不含剧情。剧情相关的问题照旧只看 `README.md` 和 `docs/玩家手册.md`。
> 这是作者第一局（seed 1118，2026 年 10 月）用的计划，"Claude"指作者用来协作的 AI 编程助手。可以照着改成你自己的。

---

## 0. 一句话定位（所有产出都围绕它）

**"我把一个混乱的市场部项目组，用飞书低代码 + AI 管顺了：工具是真的，团队是 AI 模拟的，前后数据可对比。"**

你要证明给低代码实施 / AI 提效 / 飞书数字化实施岗位看的三件事：

| 能力 | 用什么证明 |
|---|---|
| 诊断：看懂团队乱在哪 | 第 1 周的痛点笔记 + 工作量统计（`sim stats`） → 一页"问题 → 根因 → 方案" |
| 动手：用低代码 + AI 搭方案 | 第 2 周在飞书里搭工具的录屏 |
| 落地：有人用、有效果 | 模拟同事真的在用你的工具 + 第 3 周的对比仪表盘 |

最后在视频和面试里讲清楚：**哪些活交给了 AI 和自动化，哪些必须由人来做（判断、推动、取舍、向上汇报）**。

### 主线：给项目助理提效，不是取代

> **"我把项目助理 60% 的重复工作交给了 AI 和低代码工具，让人专注在判断和推动上。"**

| 幕 | 内容 | 阶段 |
|---|---|---|
| 一、我当了一周人肉项目助理 | 信息零散、口头任务被忘、日报有水分；我的精力都花在追问、手动改表、汇总上（`sim stats` 的次数） | 第 1 周 |
| 二、把重复的活交出去 | 把时间拆成"重复劳动"和"判断推动"两类；重复的交给工具，逐个搭 | 第 2 周 |
| 三、结果和边界 | 前后数据对比 + 工具起作用的关键时刻 + AI 哪里不行、为什么还需要人 | 第 3 周 + 收尾 |

- AI 机器人（群里查进度、催日报、汇总风险、周报初稿）是第二幕里的**"项目助理的 AI 副手"**，不是主角；最后判断、拍板、发出去的是人。
- 能用飞书原生功能（如"总结未读消息"）就先用原生的，不够再自己搭。这一点本身就是选型能力，视频里讲出来。
- 结尾金句（备选）："提效不是让 AI 替人干活，而是让人不用再干那些不需要人干的活。"

## 2. 准备（今天，约 30 分钟）

1. **建素材文件夹**（放在项目外面，比如桌面）：
   ```
   求职视频素材/
   ├── D1/ D2/ … D15/     每天的截图
   ├── 录屏/              第 2 周搭工具的录屏
   └── 痛点笔记.md         也可以直接写在每天的动作日志里
   ```
2. **飞书任务表回到初始状态**：新档的进度和旧档不同。
   - 在你的多维表格里新建一张表，重新导入 `docs/任务表-计划.xlsx`，命名为"任务进度（新档）"。
   - 旧的表留着别删，以后可以用来对比。
   - 新表的字段按上次的结论改好：状态改成单选，选项是 待确认 / 未开始 / 进行中 / 阻塞 / 待审核 / 已完成；备注改成多行文本。
3. **不用计时**：你每天私聊追问了多少次、手动改了多少处表，程序会自动统计，运行 `uv run sim stats` 就能看到（也存成 `output/workload.csv`）。
4. **读一遍手册**：第 2 章（同事）、第 3 章（项目）、10.11（每日工作清单）、10.1 / 10.2（纪要和周报模板）。第 7 章先扫一眼，知道有哪些"改进"可选就行。

## 3. 第 1 周：手工期（D1–D5）

这一周的目标**不是**做得漂亮，而是**真实地体验手工管理有多累**，同时留下"改进前"的数据。不要提前搭自动化，但任务表、纪要这类手工活照常做。

### 每天的流程

终端里一直开着 `uv run sim serve`，其余全在飞书里：

```
给导演发"上班"     ① 上午的消息按模拟时间陆续出现在两个群里
   ↓               ② 更新任务表：只写核实过的信息，备注写清来源
   ↓               ③ 私聊同事追问（要数字、要链接、要具体时间）；有人私聊你或 @你时时间自动暂停
   ↓               ④ 写了纪要等文档：给导演发"记录：…… + 文档链接"
给导演发"中午"     ⑤ 下午的消息：看看你上午的动作有没有回应
   ↓               ⑥ 接着干活
给导演发"下班"     ⑦ 日报和晚上的消息
   ↓               ⑧ 留素材：任务表截图、痛点笔记（写在 logs/actions/Dn.md 最后一栏）
```

### 导演怎么知道你做了什么

- **自动记录**：你在群里的发言、和同事的私聊、任务表的修改（每次发"中午""下班"时比对）。
- **需要你补一句的**：文档类产出（纪要、周报、上报材料）发"记录：……"并附上飞书文档链接，导演会读正文；线下的事（"打了个电话"）也用"记录："。
- 判断标准是实质：要了链接、问了具体数字、给王丽的是带选项的建议，而不是"问了一下进度"。

### D5（周五）的特殊任务

- **17:30 前给王丽发周报**：用手册 10.2 的模板，可以写成飞书文档后私聊发链接给她，也可以直接把全文私聊发给她。周报怎么写、从哪些地方收集信息，在痛点笔记里记一句，第 3 周用工具写时好对比。
- **周末回复**：发"下班"之后，王丽会私聊回复你的周报。

### 第 1 周结束时的产出：一页诊断

把 5 天的痛点笔记整理成一张表（视频里"诊断"那一段直接用它）：

| 痛点（现象） | 出现了几次 / 花了多少时间 | 根因 | 打算用什么工具解决 |
|---|---|---|---|
| 例：日报只写"在跟"，要一个个私聊问 | 每天约 20 分钟 | 日报没有结构，也不要求附交付物 | 日报表单 + 必填链接 + 定时提醒 |

最后一列从手册第 7 章的改进清单里选，也可以写你自己的想法。**选 3–5 个就够了**，宁少勿多，每个都要能拍出"问题 → 搭建 → 同事用起来 → 效果"的完整过程。

## 5. 第 2 周：搭工具期（D6–D10）

**每个工具都按这 5 步走，并且全程录屏**：

1. **问题**：截一张第 1 周的痛点证据，比如一条只写了"在跟"的日报。
2. **搭建**：在飞书里搭（多维表格、表单、自动化、仪表盘、机器人）。录屏可以加速，但关键配置要看得清。
3. **上线**：在群里发公告，说明怎么用、从哪天开始用，并截图。
4. **使用**：模拟同事开始用你的工具，比如往你的表单里提交日报、按需求单提需求。截下他们使用的画面。
5. **效果**：记下当天的变化，比如日报提交率、返工次数、你自己花的时间。

可以选做的工具（按"好拍、好讲"排序）：

| 工具 | 低代码部分 | AI 部分 |
|---|---|---|
| 任务中枢 + 看板 + 逾期提醒 | 多维表格、看板视图、自动化提醒 | — |
| 结构化日报 | 表单、17:30 定时提醒、交付物链接必填 | AI 汇总当天日报，标出风险 |
| 会议纪要 → 待办 | 待办表 + 新增时自动通知负责人 | AI 从纪要里提取待办 |
| 待审批汇总 | 状态变成"待审核"时自动提醒王丽 | — |
| 设计需求单 | 表单模板 | — |
| 群里问进度 | — | @助手问"A6 到哪了"，查表回答（可以改你已经做过的 `feishu-plugin/ai-bot`） |
| AI 周报初稿 | — | `uv run sim weekly --file 导出的任务表.csv`，或者做成机器人 |

注意：
- 改进上线后会**永久**改变同事的行为（手册第 7 章），所以越早上线，第 3 周的对比越明显。
- 有的同事会不愿意用新工具，这正是视频里"推动落地"的素材。不要跳过，记录你是怎么推动的。

## 6. 第 3 周：见效期（D11–D15）

- 工具照常运行，`sim stats` 会继续统计追问和改表次数，和第 1 周直接对比。
- 发布会前后节奏很快，留意工具在关键时刻起作用的例子，比如某个风险被提醒及时拦了下来。挑 1–2 个这样的瞬间，作为视频里的"高光"。
- D15 之后运行：
  ```bash
  uv run sim report     # 结局报告 + output/metrics.csv
  ```
  把 `metrics.csv` 导入多维表格做对比仪表盘（手册 9.5），由 Claude 帮你配好。

## 7. 产出（模拟结束后）

| 产出 | 内容 | 用途 |
|---|---|---|
| 主视频 5–8 分钟 | 结构见下 | 作品集、私信、邮件附链接 |
| 小红书短视频 / 图文 3–5 条 | 每个工具单独拆成一条："我用飞书 XX 解决了 XX" | 你的求职账号 |
| 一页纸 | 问题 → 方案 → 效果（带数字） | 冷邮件、内推 |
| 简历项目描述 | 3 条 bullet，每条一个数字 | 简历的"AI 提效版" |
| 面试讲法 | 手册 11.4 + 下面的"AI 和人的分工" | 面试 |

**主视频结构**（在手册 11.3 的基础上，偏向提效岗位）：

1. 开头 30 秒：前后对比的数字。
2. 背景：模拟团队是什么样的，为什么用模拟（安全的沙盘，数据可以量化）。
3. 第 1 周：手工管有多乱，用追问次数、改表次数说话。
4. 诊断：一页诊断表。
5. 搭工具：3–5 个工具，每个都按"问题 → 搭建 → 使用 → 效果"讲。
6. 第 3 周：仪表盘对比 + 1–2 个高光瞬间。
7. 反思：AI 做了什么，我做了什么；最难的是让人用起来。
8. 结尾：我能为你的团队做什么。

**诚实声明**必须带上（手册 11.5）：这是自建的模拟演练，同事由 AI 扮演；工具和搭建过程是真实的。
