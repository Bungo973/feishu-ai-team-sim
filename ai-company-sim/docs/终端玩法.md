# 终端玩法（不用飞书，备用）

推荐用飞书模式（见 `README.md`）。没有飞书、或者只想先试试规则，可以全程在终端里玩。

## 每天的循环

```
uv run sim start        → 上午的群消息（终端 / output/Dn/morning.md）
     ↓
uv run sim chat 李想     → 私聊同事（王丽、张伟、李想、陈悦、周涛、孙磊、刘敏、黄建国都可以）
写 logs/actions/Dn.md   → 你做了什么，每条前面写模拟时间 [10:30]
     ↓
uv run sim noon         → 导演结算上午的动作，下午的群消息 + 上午的导演复盘
     ↓
接着干活，日志接着往下写（时间写 12:00 以后）
     ↓
uv run sim end          → 日报、晚间消息、当天的导演复盘、（周五）王丽对周报的回复
```

- 私聊里输入 `/t 14:30` 把模拟时间调到下午 2 点半；`/q` 退出。也可以用 `uv run sim clock 15:00`。
- **动作日志不写的等于没做**：导演只认日志、私聊里有原文的动作。
- 你的动作在**当天下午或晚上**开始起作用，已经显示出来的消息不会再变。
- 忘了跑 `noon` 直接 `end`：程序会先帮你跑下午，再问你要不要直接下班。

## 把消息发到飞书群（只发不收）

不想配飞书应用，但想让视频里有飞书群的画面：

1. 在飞书里建两个群：`品牌项目组`、`小暖 S2 发布会筹备`（名字要一模一样）。
2. 群设置 → 群机器人 → 添加机器人 → **自定义机器人**。每个群至少加 1 个，Webhook 地址填到 `.env` 的 `FEISHU_WEBHOOK_TEAM_DEFAULT` / `FEISHU_WEBHOOK_LAUNCH_DEFAULT`，消息会显示成"王丽：……"。想让每个同事有自己的头像，就给每人各建一个，填 `FEISHU_WEBHOOK_TEAM_WANGLI` 这样的变量（见 `.env.example`）。
3. 预览、发送：
   ```bash
   uv run sim send morning --dry     # 只预览
   uv run sim send morning           # 发到飞书；下午 afternoon，晚上 evening
   ```
   确认没问题后，在 `.env` 里设 `FEISHU_SEND=auto`，以后每次 `start` / `noon` / `end` 自动发。

这种模式下机器人只能发、不能收：私聊仍然在终端里用 `sim chat`，你在群里说的话要抄进动作日志。
