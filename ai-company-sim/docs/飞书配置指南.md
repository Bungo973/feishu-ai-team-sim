# 飞书配置指南（飞书模式）

配好之后，整局游戏都在飞书里进行：
- 同事在群里用自己的头像说话，你可以直接私聊他们；
- 给"导演"机器人发"上班 / 中午 / 下班"推进一天；
- 你的群发言、私聊、对任务表的修改都会被**自动记录**，不用再手写日志。

终端里只需要开着一个 `uv run sim serve`，不用再管它。

> 飞书后台的界面和按钮名称会变，下面写的是常见叫法。哪一步找不到，截图问 AI 助手。

---

## 第 0 步：先做最小验证（约 20 分钟）

**先只建 2 个应用：导演 + 李想**，把整个流程跑通，确认你的飞书版本能用，再建其他人。下面每一步都先只做这两个。

---

## 第 1 步：建团队、群和任务表

1. **建一个新的飞书团队**（别用真实工作空间）：飞书 → 创建团队 / 企业，名字比如"知暖电器（模拟）"。你是管理员。
2. **建两个群**，名字必须一模一样：`品牌项目组`、`小暖 S2 发布会筹备`。
   如果之前给群加过"自定义机器人"（Webhook），**先删掉**，否则同一个同事会出现两个。
3. **建任务表**：新建一个多维表格（名字随意，比如"品牌项目组 · 项目管理"），把 `docs/任务表-计划.xlsx` 导入成一张数据表（这是前任张伟交接给你的计划表，编号怎么读见玩家手册 3.0）。
   - 列名保持 `任务、项目、负责人、状态、截止日期、前置任务、审核人、备注`，之后可以自己加列、改类型。
   - 打开这张表，复制浏览器地址栏，**链接要带 `?table=tbl…`**，第 3 步要填。

## 第 2 步：建应用（每个机器人一个）

打开 https://open.feishu.cn/app → **创建企业自建应用**。

| 应用名称（就是机器人在飞书里显示的名字） | 必须建吗 |
|---|---|
| 导演 | 必须 |
| 王丽、张伟、李想、陈悦、周涛 | 建议都建（最小验证时只建李想） |
| 其他同事 | 建议建（孙磊、刘敏、黄建国没有单独机器人时由它代发） |
| 孙磊、刘敏、黄建国 | 可选，想更好看就建 |

- **名字要和角色完全一致**（比如"李想"），你在群里 @李想 时程序靠这个名字认人。
- 头像用 AI 生成的卡通形象，不要用真人照片。

每个应用都要做这几件事：

1. **添加应用能力 → 机器人**。
2. **凭证与基础信息**：复制 App ID 和 App Secret，填进 `.env`（见第 3 步）。
3. **权限管理**：开通下面这些权限。很多版本支持"批量导入"，可以粘贴 JSON【需实测】：

   **所有同事 + 其他同事：**
   ```json
   {"scopes": {"tenant": ["im:message", "im:message:send_as_bot", "im:message.p2p_msg:readonly",
                          "im:message.group_at_msg:readonly", "im:chat:readonly"], "user": []}}
   ```
   **导演**：在上面的基础上，再加上读取所有群消息、读写多维表格、读文档的权限：
   ```json
   {"scopes": {"tenant": ["im:message", "im:message:send_as_bot", "im:message.p2p_msg:readonly",
                          "im:message.group_at_msg:readonly", "im:chat:readonly", "im:message.group_msg",
                          "bitable:app:readonly", "bitable:app", "docx:document:readonly", "wiki:wiki:readonly"], "user": []}}
   ```
   中文名大致是：获取与发送单聊和群组消息、以应用身份发消息、读取用户发给机器人的单聊消息、接收群聊中 @机器人消息、获取群组信息、**获取群组中所有消息**（导演用来采集你在群里的发言）、查看 / 编辑多维表格（你搭好日报表单后，同事的日报由导演写进「日报」表）、查看文档、查看知识库。

先别发布，接着做第 3 步。

## 第 3 步：填 `.env`

用文本编辑器打开项目里的 `.env`（`open -e .env`），参照 `.env.example` 里"飞书模式"那一段，加上：

```
FEISHU_BOT_DIRECTOR_ID=cli_xxx
FEISHU_BOT_DIRECTOR_SECRET=xxx
FEISHU_BOT_LIXIANG_ID=cli_xxx
FEISHU_BOT_LIXIANG_SECRET=xxx
FEISHU_BITABLE_URL=https://xxx.feishu.cn/base/xxxx?table=tblxxxx&view=vewxxxx
FEISHU_SPEED=15
```

- `FEISHU_BITABLE_URL`：第 1 步复制的任务表链接，**必须带 `?table=`**。
- `FEISHU_SEND` 保持 `off`。

## 第 4 步：开启长连接，然后发布

飞书要求**程序先连上**，才能在后台选择"长连接"。所以顺序是：

1. 在终端运行，并保持开着：
   ```bash
   cd ai-company-sim
   uv run sim serve
   ```
   这时可能会提示"导演不在群里"之类，先不用管。
2. 回到每个应用的后台：**事件与回调 → 订阅方式选"使用长连接接收事件"** → 保存 → **添加事件** `接收消息 v2.0`（`im.message.receive_v1`）。
3. **版本管理与发布 → 创建版本 → 发布**。你是管理员，自己审批通过。
   以后只要改了权限或事件，都要重新发布一次。

## 第 5 步：把机器人拉进群、跟每个机器人打招呼

1. 两个群都打开 **群设置 → 群机器人 → 添加机器人**，把**所有**应用机器人都加进去，包括导演和其他同事。
2. 在飞书里**私聊每个机器人，发一句"你好"**。之后它们才能主动私聊你。导演收到"你好"会回复命令列表。
3. 任务表：打开多维表格 → 右上角"…" → **更多 → 添加文档应用** → 选"导演"，给"**可编辑**"权限（同事的日报要写进你搭的「日报」表）。

## 第 6 步：检查

另开一个终端（`sim serve` 那个别关）：
```bash
uv run sim feishu-check
```
每个机器人都显示"✓ 连接正常｜在群：品牌项目组、小暖 S2 发布会筹备｜✓ 你私聊过"，任务表显示"✓ 能读到 37 行"（导入的计划表），就全部配好了。

最小验证通过后，用同样的步骤建其余机器人：第 2 → 3 → 4（`sim serve` 要重启一次，才能连上新加的机器人）→ 5 → 6。

## 怎么玩

给**导演**发：

| 命令 | 作用 |
|---|---|
| `上班` | 开始新的一天，上午的消息按模拟时间陆续出现 |
| `中午` | 结算上午、开始下午，导演私聊你上午的复盘（上午还有消息没到时会先确认，发`确定中午`才结束） |
| `下班` | 结束今天：日报、晚上的消息、当天的导演复盘，周五还有王丽对周报的回复（同样会先确认） |
| `暂停` / `继续` | 停住 / 恢复模拟时间 |
| `快进`、`快进 10:30` | 跳到下一条消息 / 跳到指定时间 |
| `速度 20` | 现实 1 分钟 = 模拟 20 分钟 |
| `状态` | 现在几点、还有多少条消息没到 |
| `记录：……` | 补记群聊、私聊、任务表之外的事。附上飞书文档链接，导演能读到正文（比如你写的纪要、周报） |

- **有人私聊你或 @你时，时间会自动暂停**，你回复后自动继续。
- **私聊同事**：直接在飞书里点开他们的机器人聊天。没有单独机器人的同事，私聊"其他同事"，开头写名字，比如"孙磊：物料清单什么时候给？"。
- **在群里 @某人**，他会在群里回你。
- **任务表**：每次发"中午""下班"时，导演会读一次表格，把你改了什么自动记进日志。
- **自动记录不到的事**（写了文档、开了会、打了电话、上线了一个流程或工具），记得发"记录：……"给导演。
- **日报表**：你按玩家手册第 9 章「表 3：日报」搭好表单并上线后，同事交的日报由导演写进这张表（表名叫「日报」）。

## 常见问题

- **机器人不回话**：先看 `sim serve` 那个终端有没有报错；再跑 `uv run sim feishu-check`。最常见的原因是改了权限没重新发布，或者机器人不在群里。
- **出错了**：导演会私聊告诉你，同时时间暂停，一般重发刚才的命令就好。终端的报错可以直接发给 AI 助手帮你看。
- **用量**：免费版自建应用的接口调用据说有月度上限（第三方资料说约 1 万次/月，以后台显示为准）。整局大约用 2000–4000 次。导演的"状态"命令会显示本次运行的调用次数。
- **想回到终端玩法**：停掉 `sim serve`，原来的 `sim start / noon / end` 照样能用。
